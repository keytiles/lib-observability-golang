## TLDR

Package `kt_observability_monitoring` wraps Prometheus so Keytiles Go services expose metrics in a **standard, constrained** way:

- Init a dedicated `MetricRegistry` with **global const labels**
- Create metrics from **templates** (fixed name + type + allowed custom label names)
- Create **instances** by filling those custom labels (no extra labels)
- Optionally use **HTTP lazy metric sets** for client/server request observability

For the overall package layout and shared labels, see [Architecture-v2.0.md](Architecture-v2.0.md).

## Package

- Path: `pkg/kt_observability_monitoring`
- Depends on: `pkg/kt_observability` (default global labels), `prometheus/client_golang`, `lib-logging-golang` (warnings on register failures)

## Init and global labels

- `InitMetrics()` — creates `MetricRegistry` and sets global labels from `kt_observability.BuildGlobalLabelsMap()`
- `GetGlobalLabels()` / `SetGlobalLabels(map[string]any)` — read/override the map used as Prometheus const labels
- `BuildMetricLabels(map[string]any) prometheus.Labels` — stringifies values for Prometheus

Call `SetGlobalLabels` **before** creating templates/instances if you need custom const labels (templates capture const labels at creation time).

## Templates vs instances

A **template** (`MetricTemplate`) holds:

- Metric type: `counter`, `summary`, or `gauge`
- Fully qualified metric name
- Allowed custom label names (the library also appends `metricType`)

Flow:

1. Get or create a template (`GetCounterMetricTemplate` / `GetSummaryMetricTemplate` / `GetGaugeMetricTemplate`, or a predefined getter below)
2. `Register(MetricRegistry)` (predefined templates register themselves on first use)
3. Create an instance with concrete custom label values:
   - `GetCounterMetricInstance`
   - `GetSummaryMetricInstance`
   - `GetGaugeMetricInstance`

Instances must supply **all** custom label names defined by the template.

## Predefined templates

Defined in [metrics_templates.go](../pkg/kt_observability_monitoring/metrics_templates.go). First access creates and registers them on `MetricRegistry`.

### Generic business metrics

Custom labels: `of`, `qualifier` (+ `metricType`)

- `execCount` — `GetExecCountTemplate()`
- `errorCount` — `GetErrorCountTemplate()`
- `warningCount` — `GetWarningCountTemplate()`
- `processingTime` (summary) — `GetProcessingTimeTemplate()`

### Sync client metrics (HTTP, gRPC, …)

Custom labels: `of`, `protocol`, `statusCode`, `qualifier`, `clientId` (+ `metricType`)

- `clientReqSentCount`
- `clientReqSuccessCount`
- `clientReqFailedCount`
- `clientReqRetriedWarnCount`
- `clientReqProcessingTime`

### Server metrics (HTTP, gRPC, …)

Custom labels: `of`, `protocol`, `statusCode`, `qualifier`, `serverId` (+ `metricType`)

- `serverServeStartedCount`
- `serverServeSuccessCount`
- `serverServeFailedCount`
- `serverServeProcessingTime`

## HTTP lazy metric sets

Convenience wrappers that create series only when first used (“lazy”).

### `HttpServerLazyMetricsSet`

- `NewHttpServerLazyMetricsSet(of, opts...)` — `of` is required (endpoint / handler name)
- Options: `WithHttpServerId`
- Methods: `ServeStarted`, `ServeSucceeded`, `ServeFailed`, `ServeTookMillis`
- Uses HTTP method as `qualifier`; `protocol` is `"http"`

### `HttpClientLazyMetricsSet`

- `NewHttpClientLazyMetricsSet(of, opts...)` — `of` is required
- Options: `WithHttpClientId`, `WithHttpClientQualifier` (older `WithClientId` / `WithQualifier` are deprecated aliases)
- Methods: `RequestSent`, `RequestSucceeded`, `RequestFailed`, `RequestTookMillis`
- Status codes are **strings** so you can pass `"200"` or ranges like `"2xx"` / `"5xx"`

## Exposing metrics over HTTP

Wire Prometheus’ handler to the library registry (as in the example app):

```go
kt_observability_monitoring.InitMetrics()
// optional: kt_observability_monitoring.SetGlobalLabels(...)

mux := http.NewServeMux()
mux.Handle("/metrics", promhttp.HandlerFor(
    kt_observability_monitoring.MetricRegistry,
    promhttp.HandlerOpts{Registry: kt_observability_monitoring.MetricRegistry},
))
go http.ListenAndServe(":9008", mux)
```
